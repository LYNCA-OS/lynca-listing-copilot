# 00 Philosophy and Definition

*Mirrored from the Linear project homepage. Linear is canonical.*

OCS is LYNCA's institutional cognition layer. It converts operational reality
into shared organizational understanding that is traceable, reasoned, learnable
and governed.

It is **not** a knowledge base, a RAG chatbot, or a founder assistant. It
preserves organizational memory, separates evidence from interpretation,
supports decision continuity, and enables governed action beyond any single
individual.

## Core operating loop

```
Operational Reality
→ Evidence
→ Organizational Memory
→ Reasoning
→ Decision Proposal
→ Authorized Decision
→ Implementation
→ Outcome
→ Learning
```

## The principle that governs the rest

> Products are replaceable interfaces. Capabilities, relationships, and
> accumulated organizational learning are the durable company assets.

## Why the evidence/interpretation split is load-bearing

This is the clause with the most operational bite, and the repository has
already paid for ignoring it. Three cases from a single day of work on the card
recognition pipeline, 2026-07-29:

- A latency figure of "10,841ms uninstrumented" was derived by subtracting
  non-nested spans, written into two documents, and became the highest-priority
  item on a task brief before anyone checked whether the subtraction meant
  anything. It did not: 29.5% of rows had a negative residual.
- "60.4% of set names uniquely identify a product-year" was measured on
  harvested data, applied to production for a week, and resolves 14% there.
- "69.3% of the model output is waste" was reasoned from until an experiment
  showed removing those fields cost 6.91 and 7.74 accuracy points.

Each began as a legitimate observation and became a canonical-sounding premise
without ever being labelled as an interpretation. That is the failure mode the
loop's separation exists to prevent.
