# 任务书 — 裸卡的版权行（提示词零成本臂）

**状态**：待创始人派发。本文件只描述该做什么和怎么判定，不含已执行的动作。

---

## 1. 为什么是这条

2026-08-03 在 150 张确认库上测出一条此前未被记录的分层：

| 切片 | 张数 | F1 |
| -- | --: | --: |
| 已评级卡 | 41 | **0.8653** |
| 裸卡 | 109 | **0.7443** |
| 差 | | **+0.1210** |

已评级卡**已经接近 0.90**，而且我们一张 grade 都没漏读（参考显示已评级、我们没读到的：0 张）。**整个准确率缺口集中在 73% 的裸卡上。**

原因不难理解：**卡壳标签是第三方替我们把身份转写好了**。PSA/BGS 标签上直接印着年份、产品、主体、插卡名、编号、评分。已评级卡的识别因此不是「看图认卡」，是「读标签」，而我们已经会读标签。

逐字段拆开，裸卡掉得最多的正是标签会写的那几项：

| 字段 | 已评级 | 裸卡 | 差 |
| -- | --: | --: | --: |
| print_finish | 0.636 | 0.470 | +0.167 |
| set | 0.800 | 0.671 | +0.129 |
| **year** | **1.000** | **0.885** | **+0.115** |
| card_name | 0.667 | 0.574 | +0.092 |
| manufacturer | 0.875 | 0.814 | +0.061 |

**year 在已评级卡上是满分。** 裸卡没有标签，它的等价物是**背面的版权行**——`2025-26 PANINI-DONRUSS ROAD TO FIFA WORLD CUP 26™ SOCCER` 这一行同时给出年份、厂商、产品。

## 2. 假设

当前提示词把模型从背面**赶走**了，却没告诉它背面的正确来源在哪。

`canonical-fields.mjs` 第 70 行，`year` 的字段描述：

> `Prefer the slab label. A statistics year on the back is not the issue year.`

对裸卡，「优先看卡壳标签」是空指令；而后半句是一条纯否定的警告。第 197 行的检查顺序里，背面只负责 `product and identity code`，未提年份。

**假设**：为裸卡指明版权行是年份/厂商/产品的权威来源，可回收 year 与 manufacturer 上的部分裸卡缺口。

## 3. 为什么不是重提已否决的方案

`accuracy-strategy-closure-audit-2026-08-02.md` 里 `Bottom-band visual view` 已判 `COST_NEGATIVE_CANDIDATE`。**必须读懂差别再动手，否则这条不该做。**

| 手段 | **加第三张图**（拼接的底部 35% 带） | **只改提示词**，背面图本来就在发 |
| 成本 | 中位延迟 +2,632ms，输入 +23.8% | 输入 token 增量 ≈ 0 |

底部带 v1 的收益「集中在 year、card name、serial」——**与本文第 1 节测出的裸卡 year 缺口方向一致**。这说明信号是真的，之前只是用贵的办法去取。本任务是同一信号的便宜取法。

## 4. 要做的事

**改动仅限提示词，不改 schema、不改 Composer、不改 CSM。**

1. `year` 字段描述改为分支式：有卡壳标签时以标签为准；**无卡壳时以背面版权行的发行年为准**，并保留「统计年份不是发行年」这条否定约束。
2. 第 197 行的检查顺序中，为背面补上「版权行给出年份、厂商、产品」。
3. 不要新增任何图片、裁切、OCR、第二次模型调用。

## 5. 判定标准

- **配对跑批**：控制臂 = 当前提示词，处理臂 = 改后提示词，**同一批卡交替调用**（不得跨时间比较，噪声会大 5.4 倍）。
- **样本**：判定需 150 张；50 张只能用于筛选。
- **门槛**：沿用现行标准 —— **≥8 胜 0 负，或 ΔF1 ≥ +0.003 且符号检验显著**。
- **必须分层报告**：裸卡与已评级卡分开出数。**若增益只出现在已评级卡上，说明机制解释错了，应判负**——本假设predicts收益应集中在裸卡。
- **成本护栏**：输入 token 增幅 > 5% 即判失败，本臂的全部理由就是它免费。
- **超 80 字符标题必须为 0。**

## 6. 明确不做

- 不加第三张图 —— 那是已判 `COST_NEGATIVE` 的路径。
- 不做自动旋转 —— 方向异常真实存在（已确认 180° 与 90° 各一例，与 `orientation-grading-color-audit` 的「未观察到」结论相反），但**零损失**：横版卡 F1 0.8914、倒置卡 0.8571、横躺卡 0.9231，均高于全体均值 0.7669。且横版卡装竖卡壳物理上无法两者同时正，旋转会把卡面转倒。
- 不动工艺词表 —— 见第 8 节。

## 7. 若本臂失败

裸卡缺口仍然存在，但下一步不再是提示词。届时应重新评估 `accuracy-strategy-closure-audit` 中标为 `UNVERIFIED` 的三条外部证据分支（写手 B 盲审、原生高分辨率队列、真实覆盖的来源图谱），而不是继续加小规则。**该文档已经判定：剩下的高价值分支都是外部证据分支，不是更多小规则。**
