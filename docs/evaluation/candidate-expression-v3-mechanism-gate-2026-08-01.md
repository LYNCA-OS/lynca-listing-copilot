# Candidate expression v3: pre-registered mechanism gate (2026-08-01)

## Hypothesis

The closed canonical form is being applied before the model has externalized
all useful information. A candidate-first response should retain more
commercially relevant identity atoms than `bounded-evidence-v2` because it
does not ask Luna to decide product versus set versus IP while it is still
reading the card.

This is an information-capture experiment, not a production-title experiment.
It tests the first half of the proposed architecture:

`images -> permissive candidate facts -> deterministic CSM/SEM admission -> Composer`

Only the first arrow is paid in this stage. Candidate facts have zero canonical,
renderer, persistence, or production authority.

## Contrary hypothesis

More freedom may only create more tokens, duplicates, and confident mistakes.
The 100-card exhaustive arm already emitted 13.83 times the canonical output
without showing a useful-output correlation. Therefore v3 is bounded to the
smallest sufficient statistic for a listing: at most 16 commercially relevant
facts, not an exhaustive transcription.

## Response contract

The experimental response contains no canonical fields and no title. It
contains `candidate_facts` plus `unreadable_regions`.

Each candidate retains:

- an open value;
- a broad kind that does not force identity into product/set/IP prematurely;
- visible or model-knowledge basis;
- image and region provenance;
- explicit uncertainty.

`model_knowledge` is allowed only as a labeled hypothesis with no claimed image
source and with uncertainty. Visible text, stamped text, logos, and visual
interpretations must point to a supplied image. No downstream resolver runs in
this stage.

## Fixed mechanism cohort

Use the existing six IDs in
`artifacts/bounded-evidence-v2/cohorts/product-mechanism-6.asset-ids.json` with
`gpt-5.6-luna`, reasoning `none`, image detail `high`, direct local dispatch,
and a fresh output directory. Cloud Run, OCR, vector retrieval, web search, a
second model call, and production persistence are absent.

The six pre-registered identity targets are:

| Card role | Target |
|---|---|
| Leaf Metal card | `Draft` |
| Common Sense Cow | `VeeFriends` |
| Michael Jordan | `MJx` |
| Adaptable Alien | `VeeFriends` |
| Paul Kasey | `Star Wars` |
| Patrick Mix | `UFC` |

Common Sense Cow visibly contains `VeeFriends` as a logo and copyright proper
noun on the back, so that target may not be labeled as model knowledge. `Draft`
may be a model-knowledge hypothesis if the full phrase is not visible, but must
then be `uncertain` and claim no image provenance.

## Stage-6 decision

Advance to zero-cost resolver work only if all conditions hold:

1. all six target atoms occur in a candidate value;
2. every visible-basis claim is verified against its stated image and no
   candidate fabricates visible provenance;
3. every model-knowledge candidate is explicitly uncertain and has no image
   provenance;
4. the parser returns at most 16 unique candidates and no schema defect;
5. median output usage is at most 400 tokens per card;
6. no candidate is copied into canonical fields, a rendered title, or storage.

Any failure is `STOP`, not a prompt tweak followed by an unrecorded rerun.

A pass is `CAPTURE_ONLY_PASS`. It proves that the expression channel can retain
these six known atoms; it does not prove an accuracy gain. Any later accuracy
decision uses the 150-card replay / 150-real-card gate, not this mechanism set.

## Zero-cost resolver stage

After a capture pass, replay the same checkpoint while developing a resolver.
The first projection may create CSM recognition candidates and alternates only.
It must not mutate the original candidate ledger or production canonical object.

Promotion priority is:

1. exact visible product-phrase extension with manufacturer/year compatibility;
2. same-value serial formatting only, such as `27/150 -> 027/150`;
3. slab-label literals and other single-role printed marks;
4. catalog/world-graph constrained hypotheses.

Finish, conflicting serial, and model-knowledge identity remain candidates until
an independent constraint leaves a unique compatible value. A single critical
false serial, product, year, grade, or finish promotion stops that resolver.

Only a resolver that creates positive paired title deltas with zero critical
false promotions earns a fresh, label-blind confirmatory call. The six known
cards remain a mechanism set and are never reported as an accuracy estimate.
