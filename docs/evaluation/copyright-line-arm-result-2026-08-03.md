## 为什么失败：版权行与卡壳标签性质相反

假设是「卡壳标签是第三方转写的身份，裸卡的等价物是背面版权行」。**前半对，后半错。**

| | 卡壳标签 | 版权行 |
| -- | -- | -- |
| 记录 | **市场身份** | **法律身份** |
| 年份 | `2024-25`（赛季） | `2025`（© 年份） |
| 主体 | `Game of Thrones`、`UCC` | `Rittenhouse Archives`、`UEFA Club Competitions` |

实际损失样本：

```
参考 2025-26 Topps Finest ...         处理 2026 Topps Finest ...            跨季塌成单年
参考 2024-25 Topps Chrome NBL ...     处理 2025 Topps Chrome ...
参考 2022 Game of Thrones ...         处理 2022 Rittenhouse Archives ...    法律主体名泄漏
参考 2023-24 Topps Chrome UCC ...     处理 2023-24 Topps UEFA Club Competitions ...
```

**提示词第 71 行本来就写着** `manufacturer: NEVER ... the copyright line, or a legal entity name`。这条约束是有来历的，而本臂把模型指向了它明令禁止的来源。写这个假设时我读到了那一行却没把它当成反证。

## 保留下来的结论

1. **已评级/裸卡 0.121 的差距是真的**（本次两臂也复现：0.8626 vs 0.7530），但**它不通过「找一个裸卡版的标签」来消除**。卡壳标签的价值在于第三方已经做了「哪些信息值得写进标题」的取舍，卡面本身没有这个东西。
2. **跨季年份是写手的系统性编辑**（358 对草稿/定稿里 ~30 次 `2025 → 2025-26`）。本臂反向破坏了它，这从负面再次确认该信号真实。
3. **基线本身上移**：对照臂 0.7830，8 月 2 日同提示词是 0.777351，差值来自本分支已含的结构化 `grading_info`（PR #182）。**+0.0056，独立于本臂成立。**

## 不要重试的形式

- 不要换个说法再指向版权行——失败原因是信息源性质不对，不是措辞。
- 不要加底部带图裁切——`accuracy-strategy-closure-audit-2026-08-02.md` 已判 `COST_NEGATIVE_CANDIDATE`。
- 若仍要攻裸卡缺口，方向应是「哪些信息值得进标题」的取舍能力，而非再找一个信息源。
